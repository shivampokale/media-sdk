Media SDK Documentation

Framework-agnostic TypeScript SDK for accessing Pexels photos and videos.

Core Features

  • Photo search
  • Video search
  • Curated photos
  • Pagination
  • Single photo and video fetch
  • View and download events
  • Error handling
  • In-memory caching

Create a Client

import { MediaClient } from "@media-sdk/media-core";

const client = new MediaClient({
  apiKey: "YOUR_PEXELS_API_KEY",
});

Search Photos

const result = await client.search({
  query: "nature",
  page: 1,
  perPage: 20,
});

Search Videos

const result = await client.searchVideos({
  query: "nature",
  page: 1,
  perPage: 20,
});

Curated Photos

const result = await client.getCurated({
  page: 1,
  perPage: 20,
});

Single Item

const photo = await client.getById(123);
const video = await client.getVideoById(123);

Events

const unsubscribe = client.subscribe((event) => {
  console.log(event);
});

client.emitView(mediaId);
client.emitDownload(mediaId);

unsubscribe();

Dependency Direction

Application -> Platform Wrapper -> media-core

React applications use @media-sdk/media-react and React Native applications use @media-sdk/media-native.
