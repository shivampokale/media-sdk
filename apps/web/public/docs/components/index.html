Media Component Library Documentation

Headless UI behavior libraries for React and React Native. Applications provide their own markup and styling.

React Package

@media-sdk/media-ui-react

Media Grid

useMediaGrid provides infinite-scroll and load-more behavior. 

const { getLoadMoreProps } = useMediaGrid({
  hasMore,
  loading,
  onLoadMore: loadMore,
});
<div {...getLoadMoreProps()}>
  Load more...
</div>

Lightbox

useLightbox manages the active item, opening, closing, navigation, keyboard controls, and focus handling. 

const {
  isOpen,
  activeItem,
  activeIndex,
  open,
  close,
  next,
  previous,
  getDialogProps,
} = useLightbox({
  items,
});

Keyboard support includes Escape, Arrow Left, and Arrow Right.

Reel Swiper

useReelSwiper provides Reel-style paging and active-item detection. 

const {
  activeIndex,
  getContainerProps,
  getItemProps,
} = useReelSwiper();
<div {...getContainerProps()}>
  {videos.map((video, index) => (
    <div
      key={video.id}
      {...getItemProps(index)}
    >
      <video
        src={video.mediaUrl}
        controls
      />
    </div>
  ))}
</div>

React Native Package

@media-sdk/media-ui-native

The React Native package provides headless Grid, Lightbox, Reel paging, and active-item behavior.

Architecture Rules

  • UI libraries do not fetch Pexels data.
  • UI libraries do not import media-core.
  • UI libraries do not import platform SDK wrappers.
  • Consumers provide markup and styling.

Dependency Direction

Web App -> media-ui-react

React Native App -> media-ui-native
